# AI Data Analytics Internship - InAmigos Foundation (IAF)

This repository contains the work completed during my AI Data Analytics Internship at InAmigos Foundation.

### 📌 Internship Overview
Worked on data collection, web scraping, and AI-powered research to analyze NGO funding, donor impact, and fundraising strategies.

### 🛠️ Tech Stack Used
- Python, BeautifulSoup, Requests, Pandas, Excel
- AI Research Tools, EDA, Data Analysis
- Generative AI for Insights & Recommendations

### 📂 Tasks Completed

**Task 1 & 2: Web Scraping of NGO Data**
- Scraped NGO websites with HTTP status 200.
- Extracted required data using HTML tags and classes.
- Cleaned and converted data into DataFrames using Pandas.
- Merged all NGO data into a single unified DataFrame using Organization Name.

**Task 3: Effect of Funding by Donors & Its Impact on Society**
- Topic: The Effect of Freezing USAID Funds and its Withdrawal from WHO and Its Impact on Society.
- Studied impact on health, vaccination, and poor/developing countries.
- Key Insights: Shift to diversified funding models, predictive supply chain AI analytics, and multi-donor cost-sharing.

**Task 4: Finding Donors**
- Understood challenges in donor acquisition and fundraising for NGOs.

**Task 5: NGO Fundraising Dynamics & AI Solutions**
- Analyzed internal/external factors affecting fundraising (transparency, reporting, location, organization type).
- Studied government, institutional, corporate, and private funding.
- **Final Recommendation:** AI-Powered Voluntary Alumni Pay-It-Forward Ecosystem for long-term NGO fundraising.

### 🎯 Key Learnings
- Enhanced web scraping and data handling skills.
- Gained experience in AI-based research and creative problem-solving.
- Understood real-world challenges of running an NGO.
